// how your 8 months run

Three modules. One full stack AI engineer.

Each module is self contained, with its own project, exam and certificate. Take the full 8-month track, or join at the module that matches where you already are.

Module01
Months 1 – 3

IT & Programming Foundations

Assumes nothing and contains no code. How computers, AI and full stack apps work, before you write a line.

  • MS Office, how LLMs work and prompt engineering
  • How the web, APIs, databases and Git fit together
// who it is for

Complete beginners. No computer or coding background needed.

Module02
Months 4 – 5

Generative AI

This is where the code starts. Python, real data, and your first chatbot grounded in real documents.

  • Python, Pandas and SQL for real data
  • LLM APIs, embeddings and RAG chatbots
// who it is for

Anyone who understands prompting and basic web concepts, or a Module 1 graduate.

Module03
Months 6 – 8

Agentic AI

A chatbot answers. An agent does. Build AI that takes real actions, then run it safely in production.

  • AI agents, LangGraph, memory and MCP
  • Multi agent systems, evaluation and deployment
// who it is for

Anyone who can already call an LLM API from code, or a Module 2 graduate.

// frequently asked questions

Straight answers.

Do I need prior coding experience?
No. Module 1 contains no programming and starts from zero, and Python begins in Module 2. If you already have basic IT skills you can join Module 1 from Month 2, and if you can already code you can join Module 2 or 3 after a short practical check.
What is the duration of this track?
The full track runs 8 months across three modules: IT & Programming Foundations (3 months), Generative AI (2 months) and Agentic AI (3 months). Each module can also be taken on its own.
Is the internship paid?
Yes. A paid internship is included as you progress through the track. You earn while you learn, working on real AI projects inside our software-house network.
What is the fee structure?
We offer 0% EMI through partner banks and merit scholarships up to 40%. Chat with an advisor for exact fee details for your situation.
