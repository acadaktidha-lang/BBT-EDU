Cloud + MLOps

Run software and AI models in production.

How your 8 months run

Three modules. One DevOps and MLOps engineer.

Each module is self contained, with its own entry requirement, project and certificate. Modules stack, so finishing all three gives you the full skill set of a DevOps and MLOps engineer.

Module 01 · The LaunchpadMonths 1 to 2

IT Basics & Prompt Engineering

Assumes nothing. Computer and office skills first, then prompt engineering from basic to advanced.

  • MS Office, how LLMs work and why they get things wrong
  • Advanced prompting, testing prompts and safe AI use
Who it is for

Complete beginners. No computer or coding background needed.

Module 02 · The DevOps ForgeMonths 3 to 5

Linux, DevOps & Cloud

Linux, networking, Git and Python first, then the tools DevOps job postings ask for most.

  • Linux, Bash, SSH, Nginx, Git, Python and SQL
  • AWS, Docker, CI/CD, Terraform, Ansible, Kubernetes and monitoring
Who it is for

Anyone comfortable using a computer and AI assistants, or a Module 1 graduate.

Module 03 · The Model FactoryMonths 6 to 8

MLOps & LLMOps

Take machine learning and LLM systems from a notebook to production, and keep them monitored and within budget.

  • MLflow, DVC, Airflow and model serving on Kubernetes and SageMaker
  • Drift monitoring, RAG, fine tuning and LLM evaluation
Who it is for

Anyone who can deploy a containerised app to the cloud with CI/CD, or a Module 2 graduate.

Certified at every step

Tested, certified, ready for the cloud.

Every module ends with a practical and theory exam. Pass it and you are certified by Big Binary Tech, ready to prepare for the cloud certifications employers ask for.

Step 01 · Practise

A quiz every two weeks

A short quiz on the last two weeks of topics catches gaps early, and two assignments a month are submitted as working code, scripts or infrastructure.

Step 02 · Get certified
Certificate of completionBig Binary Tech

Big Binary Tech certificate

Pass the practical and theory exam at the end of a module and you receive its certificate. Complete all three for the full track certificate.

Step 03 · Go global

Ready for AWS, Terraform & Kubernetes exams

Module 2 covers the core topics of AWS Cloud Practitioner, Terraform Associate, KCNA, LPI Linux Essentials and GitHub Actions. Module 3 covers AWS Machine Learning Engineer Associate.

FAQ

Ask on WhatsApp
Do I need prior cloud or coding experience?
No. Module 1 starts from zero, and Linux begins in Module 2 with no prior Linux or coding experience needed.
What is the duration of this track?
8 months across three modules: The Launchpad (2 months), The DevOps Forge (3 months) and The Model Factory (3 months). Each module has its own project, exam and certificate.
Can I join just one module?
Yes. Each module is self contained. Students with basic IT can start Module 1 from Month 2, and Module 3 starts with a practical entry evaluation.
Which certifications does it prepare me for?
Module 2 covers the core topics of LPI Linux Essentials, AWS Cloud Practitioner, Terraform Associate, KCNA and GitHub Actions. Module 3 covers AWS Machine Learning Engineer Associate.
How am I assessed?
A quiz every two weeks, two practical assignments every month and an exam at the end of every module. The exam must be passed for the module certificate.
What is the fee structure?
0% EMI available. Merit scholarships up to 40%.
