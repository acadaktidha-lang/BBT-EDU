// how your 8 months run

Three modules. One AI integrated full stack developer.

Each module is self contained, with its own project, exam and certificate. Take the full 8-month track, or join at the module that matches where you already are.

Module01
Months 1 – 3

Web & IT Foundations

Assumes nothing. From how a computer works to your first responsive, interactive website on a live URL.

  • MS Office, how the web works, HTML and CSS
  • JavaScript, Git and AI assisted coding
// who it is for

Complete beginners. No computer or coding background needed.

Module02
Months 4 – 5

Frontend Mastery

The jump from someone who can build a page to someone a team would hire.

  • TypeScript, Tailwind CSS and React
  • Next.js, AI features in the interface and SEO
// who it is for

Anyone comfortable with HTML, CSS and JavaScript, or a Module 1 graduate.

Module03
Months 6 – 8

The Engine Room

Everything behind the screen: the API, database, security, AI services, pipeline and servers.

  • Node, Express, PostgreSQL, Prisma and authentication
  • AI in the backend, testing, Docker, CI/CD and AWS
// who it is for

Anyone who can build a React or Next.js app, or a Module 2 graduate.

// frequently asked questions

Straight answers.

Do I need prior coding experience?
No. Module 1 starts from zero, including basic IT. If you already have basic IT skills you can join from Month 2, and if you already code you can join Module 2 or 3 after a short practical check.
Is this frontend or backend focused?
Both. Module 2 is the frontend (TypeScript, React and Next.js) and Module 3 is the backend, database, AI integration, Docker, CI/CD and AWS.
Is internship included?
Yes. A paid internship is included as you progress through the track.
What is the fee structure?
0% EMI available. Merit scholarships up to 40%.
